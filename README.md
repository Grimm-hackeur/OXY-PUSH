# GitPocket

Mini IDE Git mobile : connexion par Personal Access Token GitHub, liste des
dépôts, navigation dans les fichiers, éditeur avec coloration syntaxique,
commit & push directement depuis l'app.

## Compilation

Pousser sur `main`, puis Actions > Build APK > télécharger l'artifact
`gitpocket-apk`.

## Token GitHub requis

Créer un Personal Access Token (Settings > Developer settings > Tokens)
avec le scope `repo`, à coller dans l'écran de connexion.
